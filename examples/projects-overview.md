# Открытые научные проекты ИТМО

Открытый код помогает воспроизводить научные результаты, развивать идеи других
исследователей и создавать новые инструменты вместе. В этой подборке собраны
программные проекты, связанные с исследованиями и разработками Университета ИТМО:
библиотеки, инструменты, экспериментальный код и другие научные разработки.
Подборка охватывает разные направления и подразделения университета.

Если проект оказался полезен, поддержите его звездой на GitHub или расскажите
авторам, как используете их разработку.

## Проекты по годам

Список формируется автоматически по данным базы научного кода ИТМО. Каждый
репозиторий указан один раз — в разделе, соответствующем году самой ранней
связанной с ним публикации. Этот год не обязательно совпадает с годом создания
репозитория. Проекты, для которых год публикации неизвестен, приведены в разделе
«Без года».

Название проекта ведёт в репозиторий с исходным кодом, а ссылка «статья» —
к связанной публикации. Если название публикации отсутствует, приводится краткое
описание проекта, когда оно доступно.

[2022](#2022) · [2021](#2021) · [2020](#2020) · [Без года](#без-года).
